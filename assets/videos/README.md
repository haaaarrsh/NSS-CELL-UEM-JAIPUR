# Videos Directory

This directory stores video assets for the NSS CELL UEM Jaipur website:
- `uemj-building.mp4`: Academic building video footage (~339 MB)
- `uemj-drone.mp4`: Campus drone shoot video (~491 MB)

> **Note:** Raw `.mp4` files exceed GitHub's standard 100 MB per file push limit and are kept locally or managed via Git LFS / Web Compression.

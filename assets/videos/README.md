# Videos Directory

This directory stores web-optimized video assets for the NSS CELL UEM Jaipur website:
- `uemj-building.mp4`: Academic building bottom-to-top video footage for the Home page hero background (~4.35 MB)
- `uemj-drone.mp4`: Campus aerial drone shoot video for the About UEMJ section (~4.13 MB)

Both videos have been compressed under 5 MB for fast web streaming and are tracked directly in the GitHub repository.
